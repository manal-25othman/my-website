# محتوى الموقع

كل ما يظهر على الموقع موجود في هذا المجلد. عدّليه من **لوحة التحكم**
([app.pagescms.org](https://app.pagescms.org)) أو مباشرة من ملفات JSON هنا.

كل تعديل يُحفظ → ينشره Vercel تلقائيًا خلال دقيقة تقريبًا.

| الملف | المحتوى |
|---|---|
| `site.json` | **الهوية** — الاسم، المسمى، عنوان الهيرو، النبذة، الصورة، البريد، الحسابات، السيرة الذاتية، SEO |
| `projects.json` | **المشاريع** — أهم قسم. المشروع الأبرز + دراسات الحالة |
| `about.json` | شريط الإثبات · من أنا · ماذا أفعل · لماذا منال · إلى أين أتجه · التعليم · الشهادات · المحاضرات |
| `experience.json` | الخبرة المهنية |
| `expertise.json` | المهارات التقنية (خمس مجموعات) |
| `publications.json` | المقال المنشور والإصدار |
| `tiktok.json` | المحتوى التقني وحجم الجمهور |
| `legal.json` | سياسة الخصوصية وشروط الاستخدام |
| `ui.js` | نصوص الواجهة الثابتة — نادرًا ما تحتاج تعديلًا |

## قواعد مهمة

### ١. لا أرقام ولا معلومات مُختلَقة

كل ما في الموقع مأخوذ من سيرتك الذاتية أو من نصوصك أنت. أي حقل قيمته `null`
يظهر كـ «—» ولا يُملأ تلقائيًا.

### ٢. العناصر النائبة

كل نص بين قوسين مربعين مثل `[@username]` هو **عنصر نائب** يجب استبداله.
شغّلي `npm run check` لعرض ما تبقّى منها.

### ٣. الأزرار المعطّلة

الزر الذي ينقصه رابط يظهر **معطّلًا بحدود متقطّعة** بدل أن يختفي — إشارة
واضحة لك بأن هناك رابطًا ناقصًا، ولا يضلّل الزائر.

ينطبق على: زر TikTok · زر تحميل السيرة الذاتية · روابط المنشورات.

### ٤. النصوص ثنائية اللغة

معظم النصوص بالشكل:

```json
{ "ar": "النص بالعربية", "en": "The English text" }
```

لو تركتِ `en` فارغًا يُعرض النص العربي في النسخة الإنجليزية.

## المشاريع — أهم قسم لمسؤول التوظيف

كل مشروع يُعرض كـ **دراسة حالة** لا كصورة في معرض:

```
المشكلة → الحل → دوري → أبرز ما عملت عليه → التقنيات → النتيجة
```

**المشروع الأبرز** (`featured: true`) يُعرض بشكل موسّع في أعلى الصفحة
الرئيسية مع أرقامه البارزة. مشروع واحد فقط يجب أن يحمل هذه العلامة.

**حقل `metrics`** هو ما يلتقطه مسؤول التوظيف في ثانيتين — استخدميه لأرقام
حقيقية فقط (مثل «17 جدولًا مؤمَّنًا بـ RLS»).

---

## إضافة مشروع جديد

من لوحة التحكم: **المشاريع → +** ثم املئي الحقول.

أو انسخي كائنًا في `projects.json` وعدّليه. الترتيب في المصفوفة هو ترتيب
العرض. `slug` يصبح رابط المشروع: `/projects/<slug>/`.

## الصور والملفات

| الملف | المكان | ملاحظة |
|---|---|---|
| صورتك الشخصية | `src/assets/img/profile.png` | 800×800 — نفس صورتك في LinkedIn و TikTok |
| صورة المشاركة | `src/assets/img/og-cover.png` | 1200×630 |
| صور المشاريع | `src/assets/img/projects/` | اختيارية — بدونها يظهر نقش هندسي |
| السيرة الذاتية | `src/assets/files/*.pdf` | ثم اربطيها من حقل «ملف السيرة الذاتية» |

ارفعيها من لوحة التحكم مباشرة، أو ضعيها في المسارات أعلاه.

الصورة التي لا ترفعينها تُولَّد تلقائيًا كعنصر نائب معلَّم بوضوح
(`[YOUR PHOTO]`) حتى لا تُنشر بالخطأ.
