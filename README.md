# الموقع الشخصي الرسمي — الذكاء الاصطناعي والتقنية

موقع شخصي احترافي ثنائي اللغة (عربي RTL أولاً + إنجليزي)، يجمع الهوية المهنية
والمقالات والكتاب ودليل أدوات الذكاء الاصطناعي والمشاريع ومحتوى TikTok في مكان واحد.

**مبني بلا أي اعتماديات خارجية** — مولّد ثابت (Static Site Generator) مكتوب بـ Node
خالص، ينتج HTML و CSS و JS جاهزاً للنشر على أي استضافة.

| | |
|---|---|
| الصفحات | ٢٢ صفحة × لغتين = ٤٤ صفحة |
| حجم الصفحة الرئيسية | ‎~29 KB مضغوطة (HTML + CSS + JS) |
| الاعتماديات | صفر — لا npm install، لا حزم |
| الخطوط | Tajawal مستضاف محلياً (100 KB، بلا أي طلب خارجي) |
| اللغات | العربية (الجذر) · English (‎/en/‎) |

---

## ⚡ البدء

```bash
npm run dev      # بناء + معاينة على http://localhost:4321
npm run build    # بناء الموقع في مجلد dist/
npm run check    # تقرير: ما الذي لم تستبدله بعد؟
```

لا حاجة لـ `npm install` — المشروع بلا اعتماديات (Node 18+ فقط).

## ✅ قائمة الإطلاق — استبدل العناصر النائبة

كل قيمة بين قوسين مربعين `[ … ]` هي عنصر نائب. شغّل `npm run check` في أي وقت
لترى ما تبقّى. الترتيب أدناه مرتّب حسب الأهمية:

### 1. الهوية — `content/site.js` ← **ابدأ من هنا**

| الحقل | ماذا تضع |
|---|---|
| `name` | اسمك بالعربية والإنجليزية |
| `professionalTitle` | مسماك المهني — ⚠️ لا تستخدم «مهندس / باحث / مستشار / متحدث» إلا إن كان مسماك الفعلي |
| `email` | بريدك المهني |
| `location` | مدينتك ودولتك |
| `social[].url` | روابط حساباتك الحقيقية — اترك `null` لأي حساب غير موجود |
| `social[].handle` | اسم المستخدم — يُفضَّل أن يكون **متطابقاً** في كل المنصات |
| `url` | الدومين النهائي (يُستخدم في canonical و sitemap و Open Graph) |

> **مهم للهوية الرقمية:** الحسابات التي لها `url` فقط هي التي تدخل في `sameAs`
> داخل Person Schema — وهي الإشارة التي تربط موقعك بحساباتك في نظر محركات البحث.
> الحساب بلا رابط يظهر في الموقع معطّلاً ولا يُرسَل كإشارة.

### 2. الصور — `src/assets/img/`

| الملف | المقاس | ملاحظة |
|---|---|---|
| `profile.png` | 800×800 | **استخدم نفس الصورة في TikTok و LinkedIn و X** — تطابق الصورة يقوّي الهوية |
| `book-cover.png` | نسبة 2:3 | غلاف الكتاب |
| `og-cover.png` | 1200×630 | تظهر عند مشاركة الرابط |
| `apple-touch-icon.png` | 180×180 | أيقونة الهاتف |
| `favicon.svg` | — | أيقونة التبويب |

ضع الملف بنفس الاسم في `src/assets/img/` ولا حاجة لتعديل أي كود.
أي ملف لا تضعه يُولَّد تلقائياً كعنصر نائب **معلَّم بوضوح** (`[YOUR PHOTO]`).

### 3. المحتوى

| الملف | المحتوى |
|---|---|
| `content/about.js` | الإحصائيات · الاهتمامات · التعليم · الشهادات · المسار المهني |
| `content/experience.js` | الوظائف والمسؤوليات والإنجازات |
| `content/expertise.js` | مجالات التخصص |
| `content/ai-tools.js` | دليل الأدوات |
| `content/projects.js` | المشاريع |
| `content/book.js` | الكتاب |
| `content/tiktok.js` | حساب TikTok والمقاطع |
| `content/legal.js` | الخصوصية وشروط الاستخدام |
| `content/ui.js` | كل نصوص الواجهة بالعربية والإنجليزية |
| `content/articles/` | المقالات (ملفات Markdown) |

### 4. احذف المحتوى النموذجي

المقالات الثلاثة في `content/articles/` **نماذج توضيحية** — احذفها واكتب مقالاتك.
كل عنصر عليه `placeholder: true` يظهر بشارة «نموذج» ولا يُفهرَس في محركات البحث
ولا يدخل في `sitemap.xml`. احذف السطر بعد تعبئة المحتوى الحقيقي.

## 📝 كيف تضيف محتوى جديداً

### مقال جديد

أنشئ ملفاً في `content/articles/my-article.md`:

```markdown
---
title: عنوان المقال
description: وصف من سطر يظهر في نتائج البحث وبطاقات المشاركة
date: 2026-03-01
category: الذكاء الاصطناعي
tags: [الإنتاجية, أدوات]
cover: null          # أو 'img/articles/my-cover.jpg'
featured: true       # يظهر في «مقالات مختارة»
---

نص المقال بصيغة Markdown.

## عنوان فرعي
تدخل عناوين `##` و `###` تلقائياً في فهرس المقال (Table of Contents).

- قوائم
- **عريض** و *مائل* و [روابط](https://example.com)

> اقتباس
```

اسم الملف = رابط المقال: `/articles/my-article/`.
يُحسب زمن القراءة وفهرس المحتوى والمقالات ذات الصلة تلقائياً.

**نسخة إنجليزية للمقال؟** أضف `content/articles/my-article.en.md`.
إن لم توجد، تعرض النسخة الإنجليزية المقال بالعربية مع تنبيه مهذّب.

### أداة ذكاء اصطناعي

انسخ كائناً في `content/ai-tools.js` وعدّله. تحصل الأداة على صفحة مستقلة
على `/ai-tools/<slug>/` وتظهر في الدليل مع البحث والفلاتر.

> ⚠️ **لا تضع تقييماً أو مراجعة لأداة لم تجرّبها.** اترك `rating: null`
> فيظهر «لم تُقيَّم بعد» بدل رقم مُختلَق — ولا يُنتَج Review Schema أصلاً.

### مقطع TikTok

في `content/tiktok.js` ضع رابط المقطع الكامل:

```js
videos: [
  { url: 'https://www.tiktok.com/@username/video/1234567890123456789',
    title: { ar: 'عنوان المقطع', en: 'Video title' } },
]
```

يُستخرج رقم المقطع تلقائياً ويُبنى التضمين الرسمي. **لا يُحمَّل سكربت TikTok
إلا عند ضغط الزائر على «تحميل المقطع»** — حفاظاً على سرعة الصفحة وخصوصية الزائر.

### وظيفة · مشروع · شهادة

انسخ أي كائن في `content/experience.js` أو `content/projects.js` أو
`content/about.js`، ضعه في أعلى المصفوفة، وعدّل الحقول. الترتيب في المصفوفة
هو ترتيب العرض.

## 🚀 النشر

### GitHub Pages (جاهز)

الملف `.github/workflows/deploy.yml` يبني الموقع وينشره تلقائياً عند كل دفعة
إلى **الفرع الافتراضي للمستودع** (لا يهم اسمه: `main` أو غيره — يُقارَن آلياً).
الـ workflow يفعّل GitHub Pages تلقائياً عند أول تشغيل (`enablement: true`).

إن رفض التفعيل التلقائي (يحدث في بعض إعدادات المؤسسات)، فعّله يدوياً مرة واحدة من:
**Settings → Pages → Source: GitHub Actions**

ثم ضع الدومين الصحيح في `content/site.js`:

```js
url: 'https://<username>.github.io/<repo>',
basePath: '/<repo>',   // ← ضروري إذا كان الموقع داخل مجلد فرعي
```

**دومين خاص؟** اضبط `url: 'https://yourdomain.com'` و `basePath: ''`،
ثم أضف الدومين في Settings → Pages → Custom domain.

### أي استضافة أخرى

`npm run build` ثم ارفع محتويات `dist/` — يعمل على Netlify و Vercel و
Cloudflare Pages وأي استضافة ملفات ثابتة.

### متغيرات وقت البناء

```bash
SITE_URL=https://yourdomain.com BASE_PATH= GA_ID=G-XXXXXXX npm run build
```

| المتغير | الغرض |
|---|---|
| `SITE_URL` | يتجاوز الدومين المضبوط في `content/site.js` |
| `BASE_PATH` | مسار فرعي للاستضافة |
| `GA_ID` | معرّف Google Analytics |
| `TIKTOK_PIXEL_ID` | معرّف TikTok Pixel |

## 🔍 SEO والهوية الرقمية

يُولَّد تلقائياً في كل صفحة:

- عنوان ووصف فريدان · `canonical` · `hreflang` للغتين + `x-default`
- Open Graph و Twitter/X Cards
- `sitemap.xml` (مع بدائل اللغة) و `robots.txt`
- **Schema.org**: `Person` · `WebSite` · `ProfilePage` · `Article` ·
  `Book` · `SoftwareApplication` · `BreadcrumbList` · `CollectionPage` · `ContactPage`

**قاعدة صارمة مطبَّقة في الكود:** لا يدخل أي حقل في البيانات المنظمة إن كانت
قيمته فارغة أو ما زالت عنصراً نائباً. و `Book Schema` لا يُنتَج إلا إذا كان
`published: true`، و `Review` لا يُنتَج بلا مراجعة حقيقية — حتى لا يُرسَل أي
إشارة غير دقيقة إلى محركات البحث.

### بعد النشر

1. أضف الموقع إلى [Google Search Console](https://search.google.com/search-console)
   وضع كود التحقق في `seo.googleSiteVerification`.
2. أرسل `sitemap.xml`.
3. تأكد أن الرابط نفسه موضوع في نبذة كل حساب (TikTok · LinkedIn · X) —
   الربط في الاتجاهين هو ما يثبّت الهوية.

## 📊 التحليلات

**لا يُحمَّل أي سكربت تتبّع ما لم تضع المعرّفات بنفسك** في
`content/site.js → analytics`. عند التفعيل تُتتبَّع الأحداث التالية تلقائياً:

`page_view` · `article_view` · `tool_click` · `tiktok_click` ·
`social_click` · `contact_submit`

ويُحترم إعداد Do Not Track في المتصفح افتراضياً (`respectDoNotTrack: true`).

## ✉️ نموذج التواصل

الموقع ثابت — لا يوجد خادم. الوضع الافتراضي `mailto` يفتح بريد الزائر مع
تعبئة الرسالة، ويعمل فوراً بلا أي خدمة خارجية.

لاستقبال الرسائل في بريدك مباشرة، استخدم خدمة مثل Formspree أو Web3Forms:

```js
contactForm: { mode: 'endpoint', endpoint: 'https://formspree.io/f/xxxxxxx' }
```

**الحماية من السبام:** حقل خفي (honeypot) + تأخير الإرسال الفوري +
تحقق من صحة المدخلات وتحديد أطوالها قبل الإرسال.

## 🎨 التخصيص

**الألوان والخطوط والمقاييس** كلها متغيرات CSS في أعلى
`src/assets/css/styles.css`:

```css
:root {
  --accent: #2f6feb;      /* لون التمييز الأساسي */
  --accent-2: #7c5cf0;    /* اللون الثانوي للتدرجات الخفيفة */
  --wrap: 1200px;         /* أقصى عرض للمحتوى */
  --sec-y: clamp(3.75rem, 8vw, 7rem);
}
```

تغيير `--accent` وحده يعيد صياغة هوية الموقع بالكامل.
الوضع الداكن يعمل تلقائياً حسب إعداد النظام، مع زر تبديل يدوي يُحفظ محلياً.

## 🔒 قواعد المصداقية المطبَّقة في الكود

هذا الموقع يمثّل هوية مهنية حقيقية، ولذلك:

- **لا أرقام مُختلَقة.** أي قيمة `null` تظهر كـ «—» ولا تُملأ تلقائياً.
- **الإحصائيات تُحسب من المحتوى الحقيقي فقط** — المحتوى النموذجي لا يُحتسب.
- **لا مراجعات ولا تقييمات وهمية.** بلا تقييم ⇒ «لم تُقيَّم بعد».
- **لا صور مصغّرة وهمية لمقاطع TikTok.** تُعرض المقاطع ذات الروابط الحقيقية فقط.
- **المحتوى النموذجي لا يُفهرَس** (`noindex`) ولا يدخل في `sitemap.xml`.
- **بيانات Schema.org لا تحتوي على أي عنصر نائب.**

راجع `npm run check` قبل كل نشر.
